# Web equation editor

`equation-editor.js` and `equation-editor.fragment.html` are the canonical browser implementation.
A website builds publication copies from an explicitly configured `EQNEDIT64_REPOSITORY` checkout
using `--eqnedit64-repository`. Build and publish the exact reviewed source tag.

The shared interaction contract is [product parity](../docs/PRODUCT_PARITY.md).
Native/Web clipboard byte regression and real-browser tests are distinct from actual Office acceptance.
The website must update the verified executable download link together with the matching Web assets.

Verify SHA-256 for the matching tag assets. Do not retain or edit an independent homepage source copy.
